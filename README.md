## Before publishing
1. Replace `your.email@example.com` with your real email.
2. Replace the LinkedIn and GitHub placeholder URLs.
3. Put your resume PDF in this folder as `resume.pdf`.
4. Put your internship certificate PDF in this folder as `certificate.pdf`.
5. Replace the certificate placeholder with an image preview if desired.
6. Review every project claim and add only verified results/screenshots.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.
